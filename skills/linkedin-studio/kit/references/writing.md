# Writing standard (script + post copy)

Script (65-115 words, 25-40 s with v3 Liam after tighten_voice tempo 1.12)
- Line 1 = hook, lands in the first 1.5 s: a bold true claim, sharp question or striking contrast. No "In this video".
- One idea: what it is → how it works (2-3 concrete beats, use the tool's real command names) → the surprising proof → payoff/CTA.
- Every number is verified on a primary source (repo README, GitHub API, official post). Keep units and context. Cut what you can't verify.
- Write for the ear: spell out commands ("slash scrape"), avoid strings that TTS or listeners can mis-parse ("twenty first-round" → "21st round").
- End with a light CTA ("Follow for the next one"), never begging.
- Never reuse a previous script's structure word for word.

Post copy
- Instagram: hook line + 2-4 short lines of value + the CTA + **3-5 specific hashtags** (Instagram caps posts at 5; no #reels/#explore/#fyp).
- Comment-keyword CTAs are wanted (Kunal, 20 Oct 2026): 'Comment "<WORD>" for the link' in the voiceover, on screen (land CTA scene: `cta.comment_word`) and in the caption. They're paired with an Instagram comment auto-DM (keyword → DM with the repo link), so the DM really delivers; set the keyword up in the auto-DM tool before the post goes live. Keep the keyword one short word tied to the topic (JOBS, REPO, AGENT); still add the repo name to the caption for people who don't comment.
- YouTube: title ≤ 60 chars with the key noun up front; description = 2-3 lines, links, sources, credits, 3 hashtags. **No #shorts** (our videos are 16:9 landscape, not Shorts; RULES.md).
- Pinterest: keyword-rich title ≤ 100 chars, description ≤ 500 chars, link to the repo/Gumroad.
- Disclose sponsorships (#ad) in the caption, not the video.

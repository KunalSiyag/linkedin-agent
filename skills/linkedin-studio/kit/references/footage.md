# Footage standard

- Real visuals first: `capture_page` the repo (mobile dark + desktop close-ups), GitHub Trending, docs, demo GIF pages.
- Stock: Pexels (Pexels License: free commercial use, no attribution). Find ids with web search "pexels.com/video <subject>",
  then `add_footage` with the page URL (direct file resolved automatically). Prefer 9:16 originals; 16:9 is cropped to ~32% width.
- Literal to the narration ("hands typing on a laptop at night"), dark/moody clips grade best. Check each clip on a contact sheet.
- No watermarks, no third-party logos as the subject, no stock actors presented as the real person: tag them `"tag": "stock footage"`.
- Mixkit *video* is personal-use only now; don't use it. Mixkit/ElevenLabs music is fine (record the licence).
- Gather ~1.3x as many clips as scenes.
